## اصل محصول

**آفلاین‌اول + فارسی‌اول + ساده + سریع + قابل توسعه**

تاریخ‌های قابل نمایش در UI باید شمسی باشند، اعداد نمایشی فارسی و مبالغ مالی تومان. فونت فارسی Bundled و تست کامل تقویم شمسی در فازهای کیفیت/شخصی‌سازی تکمیل می‌شوند.
