# eiNote

**eiNote** is an offline-first, minimal and modern Android personal notebook and life-organizer.

The goal is simple: one calm place for notes, checklists, planning, personal finance records, important information, voice notes, photos and backups — without requiring an internet connection.

## Product principles
- Offline-first: core features work without internet.
- Minimal UI: powerful capabilities without a crowded interface.
- Fast: local-first storage and lightweight screens.
- Customizable: adapt the experience to real workflows.
- Private: personal data stays on the device by default.
- Secure: encryption, app lock, safe backup and careful permission handling.
- Extensible: modular features without a confusing interface.

## Planned capabilities
Notes and rich text, checklists and tasks, planning, personal finance, important/pinned notes, voice recordings, image/file attachments, search/tags, reminders, local backup/restore, encrypted export/import, themes and customization.

## Development
Native Android, offline-first architecture, automated APK builds through GitHub Actions.
